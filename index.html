COMO JOGAR

🚀

1. Jornada

Acompanhe um pacote de dados viajando dentro do computador. Em cada parada, descubra um novo termo.

🧩

2. Cruzadinha

Preencha o tabuleiro com os termos aprendidos. Use as pistas para lembrar cada palavra.

🖱️

3. Modos de entrada

Alterne entre digitar a resposta ou arrastar os chips de palavra até o lugar certo.

💡

4. Dicas

Use dicas se travar: categoria e letras grátis; a primeira letra custa uma estrela.
